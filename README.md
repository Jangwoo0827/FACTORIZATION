# Factorization

소인수분해를 핵심 규칙으로 삼은 2D 아이소메트릭 자동화 게임. 데스크톱과 모바일 브라우저 양쪽을 지원합니다.

기획서: [docs/GDD.md](docs/GDD.md)

## 실행

```bash
npm install
npm run dev
```

개발 서버는 LAN에 노출되므로(`server.host`), 터미널에 찍히는 Network 주소로 **실제 폰에서 바로 열어 테스트**할 수 있습니다. 터치 조작은 에뮬레이터보다 실기기에서 확인하세요.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 (HMR) |
| `npm run test` | 시뮬레이션 · 입력 · 아키텍처 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 타입 검사 후 `dist/` 로 정적 빌드 |

## 조작

| 동작 | 데스크톱 | 모바일 |
| --- | --- | --- |
| 이동 | 가운데 드래그 · WASD · 방향키 | 도구 없을 때 한 손가락, 도구 선택 시 **두 손가락** |
| 확대 | 휠 | 핀치 |
| 건설 | 좌클릭 · 좌드래그 | 탭 · 드래그 (도구 선택 상태) |
| 철거 | 우클릭 · 우드래그 | 철거 도구 선택 후 드래그 |
| 검사 | 좌클릭 (도구 없을 때) | 탭 (도구 없을 때) |
| 스포이트 | 가운데 클릭 | 롱프레스 |
| 건물 회전 | R | ↻ 버튼 |
| 시점 회전 | Q / E | ◀ ▶ 버튼 |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y | ↶ ↷ 버튼 |
| 선택 해제 | Esc | 선택된 도구 다시 탭 |

핵심 규칙: **도구를 들고 있으면 한 손가락은 건설, 두 손가락은 이동.** 도구가 없으면 한 손가락이 이동입니다.

## 구조

GDD 14.2의 계층 규칙을 따릅니다. `sim/`·`core/`·`data/`·`input/`은 **Phaser를 import하지 않으며**, `tests/architecture.test.ts`가 이를 강제합니다. 렌더러를 교체할 수 있게 하려는 의도입니다.

```
src/
  config.ts       타일 크기, 줌 범위, 시뮬 틱 등 상수
  core/           순수 계산 — 아이소 투영(iso), 드래그 경로 래스터화(line), 시드 RNG(rng)
  sim/            타일 그리드 · 건물 점유 · 배치 규칙 · 맵 생성
  data/           건물 정의 (밸런싱용 데이터)
  input/          InputAdapter (마우스/터치 통합), Command 패턴 실행 취소
  render/         Phaser 씬, 카메라, 절차적 드로잉
  ui/             DOM HUD 오버레이
tests/
```

### 알아둘 것

- **아이소 투영** (`core/iso.ts`): `tileToWorld`는 타일 **중심**을 반환하고, 역변환은 `floor`가 아니라 `round`를 씁니다. 타일의 다이아몬드가 정수 좌표를 중심으로 한 단위 정사각형에 대응하기 때문입니다. 분수 좌표를 넣으면 타일 **모서리**가 나옵니다 (`tileToWorld(x - 0.5, y - 0.5)` = 좌상단 꼭짓점).
- **드래그 건설** (`core/line.ts`): 포인터는 샘플만 보고하므로 샘플 사이를 Bresenham으로 메웁니다. 이게 없으면 빠른 드래그에서 벨트 라인이 끊깁니다.
- **지면 렌더링**: 평지는 타일 16,384개가 아니라 **폴리곤 하나**입니다. 평지가 아닌 타일만 스프라이트를 갖습니다. 축소 시 성능의 핵심입니다.
- **건설 그리드**는 도구를 들었을 때 커서 주변에만 나타납니다 (비용 상한 + 시각적 소음 감소).
